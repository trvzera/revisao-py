# Revisão Python

Revisão simples de conceitos em Python: leitura de JSON, módulos separados (`menu`, `lerJson` / `lerBanco`) e programas no terminal.

- **`revisao1`** — menu de raças de cães com preço calculado a partir de `dados.json`
- **`revisao2`** — consulta de times em `times.json` (listar, buscar por sigla, ver todos)

Execute cada pasta com `python main.py` (a partir de `revisao1` ou `revisao2`).
